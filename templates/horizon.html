The work

Proof-of-work, tuned so a general-purpose processor stays competitive. Difficulty answers the network every 60 blocks, so the spacing holds whether ten machines are mining or ten thousand.

Privacy, opt-in

MWEB lets you move value without publishing the amount. It is a choice you make per payment, not a default imposed on the chain.

Vaults

Timelocked wallet vaults hold coins for a set period and sweep them to a recovery address if something goes wrong.
