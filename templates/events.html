Events

Nothing scheduled yet.

MoonBite is pre-mainnet and built in the open. There are no conferences, meetups, or press events on the calendar. When milestones arrive, you'll know — sign up below.

MoonBite does not organise paid conferences, token sale events, or promotional launches. It is an open-source project — not an investment or a security. Any event claiming to sell MBITE or offer early access is a scam.
What to watch for

The milestones ahead

These are the real things to track. No dates are set — we'll publish them publicly on GitHub and here when they are.

🚀

Mainnet launch

The switch from testnet to a permanent, public main chain. The genesis block will be broadcast publicly. Every coin will be mined from that block forward — no presale, no allocation.

Status: not yet scheduled
📋

First exchange listing

When MBITE appears on a public exchange for the first time. This creates the first real market price — set entirely by buyers and sellers, not by us. Signed-up users will be notified first.

Status: post-mainnet
🔄

Atomic swap coordinator

The Phase 2 upgrade that automates wallet-to-wallet settlement on the internal markets page. Currently in design — the order book already works, but settlement is still manual.

Status: in development
📦

Stable binary releases

Versioned, signed node and wallet binaries with checksums, published as GitHub releases. Makes running a full node or building on top of MoonBite significantly easier.

Status: pre-mainnet priority
Participate now

You don't have to wait

The testnet is live. You can mine blocks, explore the chain, and run a node today. The community is small — your participation matters now, not just after mainnet.

⛏️

Mine on testnet

Run the miner, find blocks, and get a feel for the protocol before mainnet. Testnet rewards have no value — that's fine, mining is how you learn the system.

🖥️

Run a node

Download MoonBite Core, sync the testnet chain, and validate blocks independently. The more nodes that exist before mainnet, the stronger the launch.

💻

Follow on GitHub

Watch the repository to get notified of commits, releases, and discussion. Everything happens in the open — there's no private roadmap.

Scam warning

Watch out for impersonators

As MoonBite grows, fake accounts and scam events will appear. Here's how to tell them apart from the real project.

🚫

We never sell early access

There are no presale events, no VIP tiers, and no early investor rounds. Anyone claiming to sell MBITE before mainnet is running a scam.

🔑

We never ask for your seed

No MoonBite event, website, or representative will ever ask for your seed phrase or private key. If they do, stop and leave immediately.

📌

Official sources only

The canonical sources are this site and the GitHub repository. Treat anything else with scepticism until you can verify it traces back to one of those two.
