Events

Nothing on the calendar. Yet.

MoonBite is pre-mainnet and built in the open. No conferences, no meetups, no press events — because we won't invent one just to fill this page. When a real milestone lands, you'll hear it. Sign up below.

MoonBite runs no paid conferences, no token sales, no promotional launch parties. It's an open-source project — not an investment or a security. Any "event" claiming to sell MBITE or hand out early access is a scam. Full stop.
What to watch for

The milestones that actually matter

These are the real things to track. No dates are set — and we won't fake one. When there's a date, it goes on GitHub and here at the same time.

🚀

Mainnet launch

The switch from testnet to a permanent, public main chain. The genesis block gets broadcast in the open. Every coin is mined from that block forward — no presale, no allocation, no head start.

Status: not yet scheduled
📋

First exchange listing

The first time MBITE shows up on a public exchange. That's when a real market price appears — set by buyers and sellers, never by us. People on the list hear about it first.

Status: post-mainnet
🔄

Atomic swap coordinator

The Phase 2 upgrade that automates wallet-to-wallet settlement on the internal markets page. Still in design. The order book already works — settlement is the part that's manual for now.

Status: in development
📦

Stable binary releases

Versioned, signed node and wallet binaries with checksums, shipped as GitHub releases. This is what makes running a full node or building on MoonBite a lot less painful.

Status: pre-mainnet priority
Participate now

You don't have to wait

Testnet is live right now. Mine blocks, explore the chain, run a node today. The community is small, which means what you do counts now — not just once mainnet arrives.

⛏️

Mine on testnet

Run the miner, find blocks, and get a feel for the protocol before mainnet. Testnet rewards are worthless on purpose — mining is how you learn the system, not how you get rich.

🖥️

Run a node

Download MoonBite Core, sync the testnet chain, and validate blocks on your own. The more nodes standing before mainnet, the stronger the launch.

💻

Follow on GitHub

Watch the repository for commits, releases, and discussion as they happen. It all happens in the open — there is no private roadmap behind this one.

Scam warning

Impersonators are coming. Here's the tell.

As MoonBite grows, fake accounts and bogus events will show up. Three rules cut through almost all of them.

🚫

We never sell early access

No presales. No VIP tiers. No early investor rounds. Anyone offering to sell you MBITE before mainnet is running a scam — no exceptions.

🔑

We never ask for your seed

No MoonBite event, site, or person will ever ask for your seed phrase or private key. If someone does, they're stealing from you. Walk away.

📌

Official sources only

The only canonical sources are this site and the GitHub repository. Doubt everything else until you can trace it straight back to one of those two.
