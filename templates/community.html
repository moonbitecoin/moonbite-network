Honest status

Where things stand

We'd rather be straightforward than oversell. MoonBite is a working testnet with real proof-of-work, a real block explorer, and real wallets — but mainnet hasn't launched and the community is still forming.

✅

What works today

Testnet mines real blocks. The web wallet generates real addresses. The block explorer reads the live chain. You can run all of this yourself.

🔧

What's being built

Mainnet launch, automated atomic swaps, and the exchange listing process are the next milestones. Each one is tracked publicly on GitHub.

👋

Who's here

A small group of early miners, developers, and node operators. Nobody is getting paid to hype this — everyone is here because they find the project interesting.

Ways to participate

How to get involved

There's no signup, no membership fee, and no permission required. Pick whatever level of involvement fits your time.

⛏️

Mine the network

Run the miner and add your hashrate to the testnet. Every block you find strengthens the proof-of-work chain and earns you the block reward. No pool required — you can solo mine from day one.

Start mining →
🖥️

Run a full node

Download MoonBite Core, sync the chain, and validate every block yourself. Full nodes are the backbone of any decentralised network — the more there are, the harder the chain is to attack.

Open source

Everything is public

MoonBite is built in the open. You don't have to take anyone's word for anything — read the code yourself.

⛓️

Node (MoonBite Core)

The reference full-node implementation, built on the Litecoin-lineage codebase. Handles block validation, peer connections, and the RPC interface.

🌐

This website

The Flask application powering this site — wallet, explorer, exchange, and all — is in the same repository. You can run it locally in minutes.

🔑

Wallet & crypto

Key generation, bech32 encoding, and transaction signing all happen client-side in auditable JavaScript. No private key ever travels to the server.
