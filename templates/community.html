Honest status

Where things actually stand

We'd rather undersell than oversell. MoonBite is a working testnet — real proof-of-work, a real block explorer, real wallets. But mainnet hasn't launched, and the community is still small. Both of those things are true at once.

✅

What works today

Testnet mines real blocks. The web wallet makes real addresses. The explorer reads the live chain. And you can run every bit of it yourself.

🔧

What's being built

Mainnet launch, automated atomic swaps, and the exchange listing process are next up. Every one of them is tracked in the open on GitHub.

👋

Who's here

A handful of early miners, developers, and node operators. Nobody's on payroll to hype this. People are here because the project is genuinely interesting to them.

Ways to participate

Jump in wherever you want

No signup. No membership fee. No permission to ask for. Pick whatever level of involvement fits the time you've got.

Mine the network

Run the miner and throw your hashrate at the testnet. Every block you find hardens the proof-of-work chain and earns you the reward. No pool required — solo mine from day one.

Open source

Don't trust us. Check it.

MoonBite is built in the open. You never have to take anyone's word for anything here — the code is right there. Read it yourself.

⛓️

Node (MoonBite Core)

The reference full-node implementation, forked from the Litecoin lineage (Bitcoin below that). It handles block validation, peer connections, and the RPC interface.

🌐

This website

The Flask app behind this site — wallet, explorer, order book, all of it — sits in the same repository. Clone it and run it locally in minutes.

🔑

Wallet & crypto

Key generation, bech32 encoding, and transaction signing all run client-side in JavaScript you can audit. No private key ever leaves your browser for our server.
