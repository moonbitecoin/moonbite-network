Safety

Avoid scams.

Scammers impersonate crypto projects. Here is exactly what MoonBite will and will not do — so you can tell the real thing from a fake in seconds.

Hard rules

MoonBite will never do these things

If you see any of the following, it is a scam. Full stop.

💬
DM you first
We will never reach out to you on Telegram, Discord, Twitter/X, Reddit, email, or any other platform without you contacting us first. Anyone who does is an impersonator.
🗝️
Ask for your seed phrase or private key
No legitimate part of MoonBite — this website, the wallet app, the node, or the team — will ever ask for your seed phrase, private key, or wallet password. Anyone who does is stealing from you.
🎁
Run a presale, airdrop, or giveaway
There has been no presale, no ICO, and no airdrop. MoonBite is a fair-launch project — every MBITE is mined. Any account claiming to send you free MBITE is a scam.
📈
Promise guaranteed returns
"Double your MBITE," "guaranteed 10×," "risk-free mining pool" — none of these exist. MoonBite is experimental pre-mainnet software. Nobody can promise you a profit.
💸
Ask you to pay to receive coins
You will never be asked to send MBITE, BTC, ETH, or any currency in exchange for MBITE. Any scheme requiring you to "pay a small fee to unlock your coins" is a theft, not a promotion.
🏦
Offer custodial storage
MoonBite is self-custodial by design. We have no accounts and we never hold coins on your behalf. Anyone offering to "keep your MBITE safe in your MoonBite account" is an impersonator.
The only way

Mining is the only way to get MBITE

There is no shortcut, no early investor round, and no back-channel allocation. If a path to MBITE is not mining, it is a scam.

⛏️

Mine it yourself

Run the MoonBite node and miner on your own hardware. The block reward goes directly to the address you control. No intermediary, no signup, no fee to us.

🔮

Exchange listing — in the future

MBITE is not listed on any exchange today. When it is, we will announce it on this site only. We will never announce a listing through a cold DM or a third-party channel first.

Official channels

How to verify you're talking to the real MoonBite

Two sources. Everything else is unverified.

🌐

This website

The only authoritative MoonBite website is the one you are on right now. Check the URL bar — it should show the correct domain with a valid HTTPS lock. Any other domain is an imitation.

💻

The GitHub repository

The canonical source code and official releases live at github.com/moonbitecoin/MoonBite-Coin. Only download wallet software from the releases page there. Verify checksums before running anything.

When in doubt: do not click, do not paste your seed, do not send money. Real MoonBite software is free, open-source, and verifiable. See the legal page or the learn page if you have questions.
Stay safe

A practical checklist

Run through these before you act on anything MBITE-related you received unsolicited.

🔍

Check the URL

Scam sites copy visuals but cannot copy the domain. Look for misspellings, extra hyphens, or different TLDs (e.g. .net, .io, .xyz when the real site uses another).

🔐

Guard your seed phrase

Write your seed phrase on paper and store it offline. Never type it into a website, never paste it in a chat, never photograph it. Anyone who asks for it is stealing your coins.

📥

Download from GitHub only

Wallet binaries come from the GitHub releases page at the canonical URL above. Verify the file hash published in the release notes before running anything.

🚩

Pressure is a red flag

"Limited time offer," "act now," "only 10 spots left" — urgency is a manipulation tactic. Legitimate software does not expire, and real coins do not have exclusive access windows.

👥

Be cautious in communities

Online communities attract impersonators. Verify any account claiming to be MoonBite staff by cross-referencing the GitHub profile — there is no "official team" account on any chat platform.

🛑

Stop and look it up

If something feels off, pause. Return to this page or the GitHub repo and compare. A few minutes of verification is worth more than recovering from a theft that can't be undone on-chain.
