Safety

Spot the fakes.

Scammers impersonate every crypto project, and MoonBite is no exception. Here's exactly what MoonBite will and won't do — so you can tell the real thing from a fake in seconds.

Hard rules

MoonBite will never do these things

See any of the following? It's a scam. Full stop.

💬
DM you first
We will never message you first on Telegram, Discord, Twitter/X, Reddit, email, or anywhere else. If someone reaches out claiming to be MoonBite, they're an impersonator.
🗝️
Ask for your seed phrase or private key
No real part of MoonBite — this site, the wallet app, the node, the team — will ever ask for your seed phrase, private key, or wallet password. Anyone who asks is trying to rob you.
🎁
Run a presale, airdrop, or giveaway
No presale. No ICO. No airdrop. MoonBite is a fair launch — every MBITE is mined. Any account offering you free MBITE is a scam.
📈
Promise guaranteed returns
"Double your MBITE," "guaranteed 10×," "risk-free mining pool" — none of it is real. MoonBite is experimental pre-mainnet software. Nobody can promise you a profit.
💸
Ask you to pay to receive coins
You will never be asked to send MBITE, BTC, ETH, or any currency to get MBITE. "Pay a small fee to unlock your coins" is theft dressed up as a promotion.
🏦
Offer custodial storage
MoonBite is self-custodial by design. There are no accounts, and we never hold coins for you. Anyone offering to "keep your MBITE safe in your MoonBite account" is an impersonator.
The only way

Mining is the only way to get MBITE

No shortcut, no early investor round, no back-channel allocation. If a path to MBITE isn't mining, it's a scam.

⛏️

Mine it yourself

Run the MoonBite node and miner on your own hardware. The block reward goes straight to an address you control. No middleman, no signup, no fee to us.

🔮

Exchange listing, later on

MBITE isn't listed on any exchange today. When it is, we'll announce it on this site only. We will never break the news through a cold DM or a third-party channel first.

Official channels

How to know it's really MoonBite

Two sources. Treat everything else as unverified.

🌐

This website

The only authoritative MoonBite website is the one you're on right now. Check the URL bar — the correct domain, a valid HTTPS lock. Any other domain is a copy, no matter how good it looks.

💻

The GitHub repository

The real source code and official releases live at github.com/moonbitecoin/MoonBite-Coin. Only download wallet software from the releases page there, and verify the checksums before you run anything.

When in doubt: don't click, don't paste your seed, don't send money. Real MoonBite software is free, open-source, and verifiable. Questions? See the legal page or the learn page.
Stay safe

A checklist that actually helps

Run through these before you act on anything MBITE-related that showed up unsolicited.

🔍

Check the URL

Scam sites copy the look but can't copy the domain. Watch for misspellings, extra hyphens, or a swapped TLD (.net, .io, .xyz when the real site uses another).

🔐

Guard your seed phrase

Write your seed phrase on paper and keep it offline. Never type it into a website, never paste it in a chat, never photograph it. Anyone who asks for it is stealing your coins.

📥

Download from GitHub only

Wallet binaries come from the GitHub releases page at the canonical URL above — nowhere else. Check the file hash in the release notes before you run anything.

🚩

Pressure is a red flag

"Limited time offer," "act now," "only 10 spots left" — urgency is the manipulation. Real software doesn't expire, and real coins have no exclusive access window.

👥

Be careful in communities

Online communities pull in impersonators. Cross-check any account claiming to be MoonBite staff against the GitHub profile. There is no "official team" account on any chat platform.

🛑

Stop and look it up

If something feels off, stop. Come back to this page or the GitHub repo and compare. A few minutes of checking beats trying to reverse an on-chain theft that can't be undone.
