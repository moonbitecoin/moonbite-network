SECURITY BEST PRACTICES:
=========================

TIER 1 - BEGINNER:
- Use hardware wallet if possible
- Never share seed phrase with anyone
- Write seed on paper, store in fireproof safe
- Verify every word in backup before confirming
- Test recovery on spare device
- Use strong, unique password
- Enable biometric authentication
- Keep small amounts in hot wallet

TIER 2 - INTERMEDIATE:
- Use multi-signature (2-of-3 setup)
- Split backups geographically
- Use air-gapped signing for large transactions
- Verify transactions on separate device
- Use custom RPC nodes for privacy
- Keep only active trading funds in hot wallet
- Regular transaction audits
- Monitor seed phrase backup security

TIER 3 - ADVANCED:
- Implement cold storage architecture
- Use multi-sig with hardware wallets (3-of-5)
- Automate tax reporting
- Use privacy features (CoinJoin, Tor)
- Implement timelock vaults
- Air-gapped signing for all transactions
- Regular security audits and penetration testing
- Segregate wallets by purpose

RECOVERY IF COMPROMISED:
=========================
IMMEDIATE ACTIONS (Do within minutes):
1. Stop all transactions immediately
2. Check transaction history for unauthorized transactions
3. Note transaction hash, amount, recipient address
4. Check blockchain explorer for confirmation
5. Generate new address within same wallet
6. Move remaining funds to new address ASAP
7. Do NOT close wallet yet (monitor for more txs)

FOLLOW-UP ACTIONS (Within hours):
8. Create entirely new wallet if funds significant
9. Report to wallet provider support
10. Document all evidence (screenshots, hashes)
11. File police report for records
12. Monitor old address for return transactions

ASSESSMENT (First 24 hours):
13. Determine how compromise occurred
14. Check for malware on device
15. Change passwords on all financial accounts
16. Enable 2FA on all exchanges/accounts
17. Monitor credit for fraud

RECOVERY CHANCES:
- Blockchain transactions: IRREVERSIBLE (cannot undo)
- Stolen funds: Nearly impossible to recover
- Best defense: Prevention through security practices

COMMON MISTAKES & SOLUTIONS:
=============================

MISTAKE #1: Using Same Password Everywhere
- WRONG: All accounts use "MyPassword123"
- RIGHT: Use unique password for each wallet
- TOOL: Password manager (1Password, Bitwarden)
- RESULT: If one account breached, others still safe

MISTAKE #2: Never Testing Seed Phrase Recovery
- WRONG: Backed up seed, never verified it works
- RIGHT: Test recovery on new device (with test amount)
- RIGHT: Verify every word is correct before final backup
- RIGHT: Test recovery every 6 months
- RESULT: Know backup actually works before needed

MISTAKE #3: Storing Seed Phrase Digitally
- WRONG: Seed in email, cloud drive, screenshot
- RIGHT: Write on paper with pen or metal backup
- RIGHT: Store in fireproof safe or safety deposit box
- RIGHT: Maintain multiple locations geographically
- RESULT: Seed safe from digital theft

MISTAKE #4: Clicking Unknown Crypto Links
- WRONG: "Verify your wallet" email link (PHISHING)
- WRONG: "Claim free airdrop" links (MALWARE)
- WRONG: "Confirm transaction" notifications (FAKE)
- RIGHT: Go directly to official websites
- RIGHT: Bookmark official sites, verify URLs carefully
- RIGHT: Never trust unsolicited links
- RESULT: Avoid malware and phishing

MISTAKE #5: Granting Unlimited Token Approvals
- WRONG: "Approve unlimited" for token swaps
- RIGHT: Set spending limit to exact amount needed
- RIGHT: Revoke approvals after use (etherscan.io)
- RIGHT: Use "Approve once" when available
- RESULT: Limit damage if smart contract hacked

MISTAKE #6: Not Using Hardware Wallet for Large Amounts
- WRONG: Software wallet with $500k holdings
- RIGHT: Hardware wallet for $10k+ amounts
- RIGHT: Multi-sig setup for $100k+ amounts
- RIGHT: Professional custody for $1M+ amounts
- RESULT: Dramatically improved security

MISTAKE #7: Ignoring Security Updates
- WRONG: Using outdated wallet version (old bugs)
- RIGHT: Enable auto-updates on mobile apps
- RIGHT: Check desktop apps monthly for updates
- RIGHT: Install security patches immediately
- RESULT: Protected against known vulnerabilities

MISTAKE #8: Sharing Recovery Information
- WRONG: Telling family/friend your seed phrase
- WRONG: Sharing private key via email
- WRONG: Letting someone "help" with recovery
- RIGHT: Seed phrase is solo secret
- RIGHT: Never share with anyone, for any reason
- RIGHT: Even banks/wallet providers never ask
- RESULT: Prevent unauthorized access

MISTAKES #9: Using Wallet Address as Personal Identity
- WRONG: Posting public address on social media
- WRONG: Linking wallet to personal identity
- WRONG: Using same address for all transactions
- RIGHT: Generate fresh address for each payment
- RIGHT: Use watch-only address if must post
- RIGHT: Maintain privacy separation
- RESULT: Prevent address-to-person correlation

MISTAKE #10: Ignoring Tax Implications
- WRONG: No record of transactions
- WRONG: Treating all gains as capital only
- RIGHT: Keep detailed transaction records
- RIGHT: Report staking/DeFi as ordinary income
- RIGHT: Report capital gains separately
- RIGHT: Use tax software (Koinly, CoinTracker)
- RIGHT: Report to tax authorities
- RESULT: Legal compliance, avoid IRS penalties
